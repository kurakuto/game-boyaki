ストーリー概要と全体の流れ

仁王3のメインストーリーは全部で18ミッション構成。プロローグに始まり、戦国・平安・古代・幕末と複数の時代を飛び越えながら物語が進む、シリーズ最大規模のボリュームを誇る作品だ。

🗾
// ストーリー全体マップ（スクショ差し替え予定）
▲ 時代をまたぐストーリーの全体像

主人公は国松と行動をともにし、妖（あやかし）と人間の境界線が崩れかけた世界を駆け抜ける。柳生宗矩をはじめとする歴史上の人物たちが個性的な敵・味方として登場し、単なる「妖退治」にとどまらない深いドラマが展開される。

// POINT — 真エンドを目指すなら

「国松選択」の分岐がエンディングを左右する。真エンドを見たい場合は、幕末篇の沖田奇譚をクリアしてから進むのがポイント。詳しくはエンディング分岐セクションで解説。

プロローグ

⛩️
// ERA: PROLOGUE
始まりの地
キャラクリ完了後、道場へ。宗矩と対面する導入パート。
// MISSION 01
始まりの道場
⚔️ ボス：なし（チュートリアル）
キャラクターを作成したら国松に続いて道場へ向かい、柳生宗矩と会話する。ここでゲームの基本操作と構えシステムを習得できる。急がずにしっかり動き方を体に馴染ませよう。
// TIP — 序盤の立ち回り

構えは「上段・中段・下段」の三種類。序盤は中段がバランス良くおすすめ。気力管理を意識しながら戦うのが仁王3の基本。

🥋
// プロローグ：道場シーン（スクショ差し替え予定）
▲ 宗矩との邂逅。ここから壮大な旅が始まる

戦国篇（全5ミッション）5 MISSIONS

⚔️
// ERA: 戦国
乱世の戦場
安土桃山の世。妖が跋扈する戦場を駆け抜ける最初の本編パート。
進捗2/18
// MISSION 02
妖刀の噂
⚔️ ボス：妖刀使い（中ボス級）
戦国篇の入口。まず城下町の周辺を探索し、妖の気配を追う。ボスは弾き（はじき）のタイミングが重要。無理に攻め込まず、気力を切らせてから追撃するのが基本。
// MISSION 03
鬼哭の城
⚔️ ボス：鬼将（戦国武将型）
城内を進む探索型ミッション。分岐路が多いので祠（ほこら）を見つけたら必ず立ち寄ること。ボスは複数形態アリ。第一形態は正面から、第二形態は側面への回り込みが有効。
🏯
// 戦国篇：城内探索（スクショ差し替え予定）
▲ 鬼哭の城。道に迷いやすいので祠の位置を覚えておこう
// MISSION 04
血染めの野
⚔️ ボス：大妖（巨人型）
開けたフィールドでの戦い。ボスは巨体ゆえ攻撃が大きいが、足元への攻撃が効果的。スタミナ（気力）を回復させながら戦う長期戦になる。
// MISSION 05
乱世の終焉
⚔️ ボス：国松の宿敵（人型ボス）
国松の過去に迫る重要な物語ミッション。ボスは高速移動が特徴的で、見切り（カウンター）を決めると大ダメージを狙える。
// MISSION 06
鬼神降臨
⚔️ ボス：鬼神（戦国篇ラスボス）
戦国篇の締め。ボスは3形態あり、最終形態では属性攻撃（炎・雷）が激化する。属性耐性の高い防具を装備してから挑もう。
// CAUTION — 戦国篇ラスボス

鬼神の第三形態は全攻撃に炎属性が付与される。炎耐性の守護霊か防具を用意しておくと格段に楽になる。無対策だと即死級のダメージを受けることも。

平安篇（全5ミッション）5 MISSIONS

🌸
// ERA: 平安
雅と妖の都
時代が跳ぶ。平安の都、陰陽師たちが妖と戦う世界へ。
進捗7/18

平安篇に突入すると世界観が一変。陰陽師や式神を使う敵が増え、属性攻撃への対策がより重要になる。ここから式神システムが本格的に活用できるようになる。

// MISSION 07
鬼の棲む都
⚔️ ボス：都の鬼将
平安の都を舞台にした探索ミッション。入り組んだ路地が多い。遠距離攻撃を使う陰陽師型の敵が増えるので、壁を盾にしながら接近する立ち回りが有効。
// MISSION 08
式神の森
⚔️ ボス：上位式神
森の中に展開するステージ。妖の気配が強く、エリア全体に毒の霧が漂う箇所がある。毒耐性か解毒丹を多めに持っていくこと。
🌙
// 平安篇：夜の都（スクショ差し替え予定）
▲ 月明かりに照らされた平安の都。雰囲気は最高だが敵も強い
// MISSION 09
陰陽の裂け目
⚔️ ボス：陰陽師・上位
時代の裂け目が発生するギミックが登場。特定のエリアでは敵が強化される「妖の領域」が展開される。領域に長居せず、素早くボスを倒すのが攻略の鍵。
// MISSION 10
宿命の相克
⚔️ ボス：宿命の敵（人型）
物語の核心に触れる重要ミッション。ボスは主人公と同じ構えシステムを使ってくる強敵。弾きと見切りを積極的に活用して主導権を握ること。
// MISSION 11
天地の鬼神
⚔️ ボス：天地鬼神（平安篇ラスボス）
平安篇の集大成。ボスは空中攻撃と地上攻撃を組み合わせてくる難敵。雷属性攻撃に注意しながら、地面に落ちてきた瞬間を狙って一気に攻め込むパターンが有効。

古代篇（全2ミッション）2 MISSIONS

🏛️
// ERA: 古代
神話と妖の原点
日本の神話時代。妖の起源に迫る謎多きパート。
進捗12/18

古代篇はミッション数こそ少ないが、ストーリーの核心が明かされる非常に重要なパート。妖が生まれた起源と、主人公の出自に関わる衝撃的な真実が語られる。

// MISSION 12
神代の祭壇
⚔️ ボス：古代の大妖
雰囲気が一気に変わり、神話的な空間を探索するミッション。これまでの常識が通じない特殊なボスが登場する。弱点属性を見極めるのが最優先。
// MISSION 13
始原の鬼
⚔️ ボス：始原の鬼（古代篇ラスボス）
古代篇のラスボスは仁王3屈指の難ボス。攻撃パターンが多彩で、すべての属性攻撃を使ってくる。最高レアリティの防具と守護霊を揃えてから挑みたい。
// CAUTION — 古代篇ラスボスへの備え

始原の鬼は全属性攻撃を使う。バランス型の耐性を持つ防具セットで挑むか、体力盛りのビルドで強引に突破するのが現実的。気力消費が激しいため、気力回復速度の高い装備も重要。

帰還1 MISSION

🌅
// ERA: 帰還
現代への回帰
時代をまたいだ旅の後、主人公が戻る場所とは。
// MISSION 14
帰還の地
⚔️ ボス：なし（ストーリー重視）
戦闘よりストーリーが主体のミッション。ここで国松との関係が大きく動く。エンディング分岐に直接関わる選択が発生するため、集中してムービーを見ること。
// BRANCH — ここが分岐点

帰還ミッションでの国松への対応が、その後の展開とエンディングに影響する。真エンドを狙う場合、ここまでに沖田奇譚をクリア済みにしておく必要がある。

幕末篇（全3ミッション）3 MISSIONS

🗡️
// ERA: 幕末
動乱と剣客の時代
幕末の志士たちが登場。沖田総司をはじめとする剣客との戦い。
進捗15/18
// MISSION 15
沖田奇譚
⚔️ ボス：沖田総司（妖化）
真エンドへの重要ミッション。沖田総司が妖の力に侵された姿で登場する。非常に高速な突きが特徴的で、見切りのタイミングが非常にシビア。焦らず連続突きのパターンを覚えよう。
// TIP — 沖田総司の攻略

沖田の必殺「三段突き」は3回目の突きだけを弾くと大きな隙を作れる。最初の2発はガードで受けて3発目に弾き、そこから一気に攻め込む。習得するまで練習あるのみ。

⚔️
// 沖田総司戦（スクショ差し替え予定）
▲ 妖化した沖田との激闘。スピードに惑わされないのが鍵
// MISSION 16
動乱の剣
⚔️ ボス：幕末の剣鬼
幕末の街並みを舞台にした爽快感あるミッション。複数の中ボスが連続で出現するため、消耗を抑えた立ち回りが求められる。各中ボスを倒した後に短いリペアタイムがあるので活用しよう。
// MISSION 17
幕末の鬼神
⚔️ ボス：幕末篇ラスボス（2形態）
幕末篇の締めは2形態ボス。第一形態は剣術特化の人型、第二形態は妖化した巨大形態に変貌する。形態移行時に一定時間隙ができるので、溜め攻撃や奥義で大ダメージを狙うチャンス。

決戦（最終ミッション）1 MISSION

🔥
// ERA: 決戦
すべての決着
時代を超えた戦いの最終局面。ラスボスと運命の対決。
進捗18/18
// MISSION 18 — FINAL
決戦・時代の覇者
⚔️ ボス：最終ボス（3形態）
仁王3の真のラスボス。全武器種・全属性に対応した攻撃を繰り出す強大な存在。3形態制で、それぞれ攻撃パターンが大きく変わる。回復薬を最大まで補充してから挑むのが鉄則。
// CAUTION — 最終ボスへの準備

ラスボスは非常に手強い。装備レベルを十分に上げ、強い守護霊と揃え効果のある防具セットで挑もう。どうしても勝てない場合は、一度幕末篇のミッションに戻って装備を整えるのが現実的。

// TIP — 最終ボス第三形態

第三形態は全ての時代の敵の技を使ってくる。落ち着いてパターンを見極め、無理な攻撃は控えて弾き・見切りを軸に戦うのがおすすめ。焦りが一番の敵。

🏆
// ラスボス戦（スクショ差し替え予定）
▲ すべての戦いの集大成。ここまで来た感動は格別

エンディング分岐について

仁王3には通常エンドと真エンドの2種類のエンディングが存在する。分岐条件は主に2つ。

// BRANCH CONDITIONS — 真エンドの条件

① 幕末篇の「沖田奇譚」をクリア済みであること
② 帰還ミッションでの「国松選択」で正しい選択肢を選ぶこと

どちらか一方でも欠けると通常エンドになる。初見で真エンドを目指すなら、沖田奇譚を先に攻略してから帰還ミッションに進もう。

真エンドでは通常エンドでは語られない物語の真相が明かされ、国松の本当の姿と主人公の出自が明確に描かれる。ぜひ両方のエンディングを体験してほしい。

まとめ

仁王3のメインストーリーは全18ミッションと大ボリューム。戦国・平安・古代・幕末と時代を飛び越えながら展開する物語は、シリーズ最高峰と言っていい出来栄えだ。

真エンドを目指すなら沖田奇譚クリア→帰還ミッションの国松選択の流れを忘れずに。ラスボス前の装備準備も怠らないようにしよう。

個人的に一番しんどかったのは古代篇ラスボス。あそこで3時間溶かした。同士よ、頑張れ。
